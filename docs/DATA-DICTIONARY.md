# 财周对照台数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 门店财周单 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 上年期首、上年周数、本年期首、本年周数、上年日销售、本年日销售 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |
| 上年促销日、本年促销日 | 可选，两年同场促销的活动日期，半角分号分隔。留空或占位符表示未提供，`无` 表示该年明确没有同场促销。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名；促销日期也接受 `上年促销日期`、`上年同场促销日`、`上年活动日` 与对应的本年写法。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

促销日期也可以单独提交一张对照表（`门店财周单,上年促销日,本年促销日`），由工作台并入复算。来源行自带日期时以来源为准；来源留空时用对照表补缺。同一天重复写只计一次，行序与日期书写顺序不影响批次指纹。

## 计算字段

日销售写成 `日期:销售额` 或 `日期:停业`。财年期首为周一，两财年连续，季度前两期各四周，第三期五周。

自然日按距期首的天数配对。第 53 周另记，零销售是营业记录，单边或停业不参与差额。

### 两种对齐

| 对齐 | 何时使用 | 配对方式 |
|---|---|---|
| 财周 | 未提供两年促销日 | 同周同星期，保持星期结构，看整段经营走势 |
| 促销进度 | 两年同场促销日均已提供 | 按活动第几天对齐（第1天对第1天），看出活动本身的涨跌 |

促销进度对齐只看促销日：第 N 个促销日与对面第 N 个促销日配对，普通营业日不会被拉来补缺；同一天重复登记只算一次。促销挪周仍可配对并记 `week_shift`，同星期与否单列。一边少办、当天无日销、当天停业、对面不可比、落在第 53 周的促销日一律落单并给出原因 `PROMO_SHORT`、`PROMO_NO_DATA`、`PROMO_CLOSED`、`PROMO_PAIR`、`PROMO_LEAP`，不进入差额。财周差额同时保留为参照 `fiscal_amount`。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `门店财周单` 和 `外部记录值(元)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **元**，有促销日期时按本次可比差额对账。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次。批次身份由规范化后的促销日期参与计算：拆分写法、重复日期或行序不同仍是同一批。重跑同一批不新增记录。导出包含两个文件摘要、证据行、单边差异和复核修订记录，并带促销配对与落单明细。复核保存前检查当前版本，在有隔离、差异、促销落单或退回时必须填写意见。
